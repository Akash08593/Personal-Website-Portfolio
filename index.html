Major / Flagship Project AI + Cloud Systems

Cloud Optimization — Multi-Cloud Resource Allocation System

Built a multi-cloud resource allocation system using LSTM and Particle Swarm Optimization (PSO) to forecast demand and optimize resource distribution across AWS, Azure, and GCP.

The Problem

Cloud workloads fluctuate significantly over time, creating critical bottlenecks in manual resource provisioning, causing unpredictable latency spikes, and increasing operational expenditure across multi-cloud environments.

The Solution

Developed an automated end-to-end pipeline that employs Long Short-Term Memory (LSTM) neural networks to forecast incoming traffic and Particle Swarm Optimization (PSO) to determine cost- and latency-optimal workload splits across AWS, Azure, and GCP.

Key Technical Components:

  • LSTM Time-Series Model: Predicts incoming workload demand using historical traffic sequences.
  • Particle Swarm Optimization (PSO): Iteratively solves multi-objective resource splits to balance cost and latency.
  • Multi-Cloud Distribution: Intelligently allocates instances across AWS, Azure, and GCP.
  • React + Vite Analytics Dashboard: Visualizes real-time allocation decisions, swarm convergence, and provider metrics.

Smart Water Quality Assessment and Early Warning System for Rural Areas

An AI-powered IoT system that monitors water quality in real-time and uses predictive analytics to detect early contamination trends, classify disease outbreak risks, and trigger automated alerts.

Problem

Rural communities frequently lack real-time water monitoring, resulting in delayed responses to contamination outbreaks and reactive water safety interventions.

Solution

Deployed IoT sensor arrays with predictive machine learning algorithms to continuously track physical/chemical metrics, categorize risk levels, and dispatch proactive alerts via GSM and Wi-Fi.
